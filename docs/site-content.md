# 公開ページの文面（Googleサイト貼り付け用）

App Store Connect には「プライバシーポリシーURL」と「サポートURL」の登録が必須で、
どちらも**ログインなしで誰でも開ける**必要がある。

GitHub Pages ではなく Googleサイトで公開する。App Store Connect に
`github.io` のURLを載せるとソースの所在が分かってしまうため。

問い合わせ窓口はメールアドレスを公開せず、**Googleフォーム**で受ける。

以下はそのまま貼り付けられる本文。HTMLタグは使わず、Googleサイトの見出し機能で
「■」の行を見出しにすればよい。

このアプリは**完全無料**（App内課金・広告・サブスクリプションなし）で、**通信を一切行わない**。
姉妹アプリの文面から、課金に関する記述をすべて落としてある。

---

## サイト全体の設定

| 項目 | 値 |
| --- | --- |
| サイト名 | 公共・政治経済特訓 |
| ウェブアドレス | `seikei-tokkun`（`AppConfig` に埋め込み済み。**変更しないこと**） |
| ページ構成 | ホーム / プライバシーポリシー / サポート |

`AppConfig.privacyPolicyURL` と `AppConfig.supportURL` が指すURLと一致させること。
食い違うとアプリ内のリンクが404になり、審査で指摘される。

## ページ2: プライバシーポリシー

見出し（大）:

```
プライバシーポリシー
```

```
公共・政治経済特訓（以下「本アプリ」）における利用者情報の取り扱いについて説明します。

■ 収集する情報

本アプリは、利用者の個人情報を一切収集しません。
氏名、メールアドレス、電話番号、位置情報、連絡先、写真などを取得することはありません。
アカウントの登録も必要ありません。

■ 学習データの保存先

解答の記録、習熟度、学習日数などの学習データは、すべて利用者の端末内にのみ保存されます。
開発者を含む第三者がこれらのデータを閲覧することはできません。

■ 通信

本アプリは、インターネット通信を一切行いません。
アクセス解析ツールや広告配信ネットワークも利用していません。

■ 第三者への提供

収集する情報がないため、第三者へ提供する情報もありません。

■ データの削除

学習データは端末内にのみ保存されているため、本アプリを削除すると、
端末上の学習データもあわせて削除されます。

■ 子どものプライバシー

本アプリは利用者の年齢に関する情報を取得しません。
いずれの年齢の利用者についても、個人情報を収集することはありません。

■ 本ポリシーの変更

内容を変更する場合は、本ページを更新します。

■ お問い合わせ

本ポリシーに関するご質問は、サポートページのお問い合わせフォームよりご連絡ください。

制定日: 2026年◯月◯日
```

## 公開前の確認

1. Googleフォームを作る（氏名不要・内容・任意のメールアドレスの3項目で足りる）
2. Googleサイトで3ページを作り、フォームを埋め込む
3. 公開後、**ログアウトした状態（シークレットウィンドウ）で両URLが開けることを確認する**
   （社内公開のままだと審査で開けず、その一点で差し戻される）
4. `AppConfig.privacyPolicyURL` / `AppConfig.supportURL` のTODOを実URLへ差し替える
5. App Store Connect の「プライバシーポリシーURL」「サポートURL」に同じURLを登録する
